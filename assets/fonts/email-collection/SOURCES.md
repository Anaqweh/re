# Email font sources

Google Fonts CSS API supplies original font files from fonts.gstatic.com. Only the families used in a message are requested. Local IBM Plex Sans Arabic retains its bundled OFL license. No commercial system fonts are bundled; the stack uses them only if installed.

- Noto Naskh Arabic: https://fonts.google.com/specimen/Noto+Naskh+Arabic
- Noto Sans Arabic: https://fonts.google.com/specimen/Noto+Sans+Arabic
- Cairo: https://fonts.google.com/specimen/Cairo
- Tajawal: https://fonts.google.com/specimen/Tajawal
- Almarai: https://fonts.google.com/specimen/Almarai
- Changa: https://fonts.google.com/specimen/Changa
- Amiri: https://fonts.google.com/specimen/Amiri
- Readex Pro: https://fonts.google.com/specimen/Readex+Pro
- Alexandria: https://fonts.google.com/specimen/Alexandria
- Inter: https://fonts.google.com/specimen/Inter
- Lato: https://fonts.google.com/specimen/Lato
- Open Sans: https://fonts.google.com/specimen/Open+Sans
- Roboto: https://fonts.google.com/specimen/Roboto
- Source Sans 3: https://fonts.google.com/specimen/Source+Sans+3

Published weights are selected from original available files. Webfont support depends on the email client; each family has system fallbacks.
